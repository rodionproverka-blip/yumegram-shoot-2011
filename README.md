# Съёмочная карта YumeGram на 20 ноября

Локальный сайт с восемью роликами, 71 сценой и 79 визуалами. У каждой сцены есть постановка, проверка дубля и изображение. Реквизит объединён в общий список и связан с отдельными роликами.

Открыть запущенный проект можно по адресу http://127.0.0.1:8780/.

## Запуск

Дважды нажмите `Запустить.command`, затем откройте адрес выше. Либо выполните из этой папки `python3 serve.py --port 8780`. Сервер использует стандартную библиотеку Python.

Отметки хранятся на этом Mac в `data/checklists.sqlite3`. Вкладки и браузеры, подключённые к одному серверу, получают общие отметки примерно раз в пять секунд. При временной потере соединения операции сохраняются в браузере и отправляются повторно после подключения. Повтор одной операции не создаёт вторую запись. Для переноса отметок сохраняйте папку `data` вместе с проектом.

По умолчанию сайт доступен на этом компьютере. При необходимости работы устройств в одной локальной сети сервер можно запустить с `--host 0.0.0.0` и открыть локальный адрес Mac на других устройствах. Текущее превью использует 127.0.0.1.

## Содержимое

- `dist` содержит сайт, актуальные сценарии в `plan.js`, готовые кадры и копии исходных документов.
- `serve.py` запускает сайт и общую базу отметок.
- `tools/build_plan.py` содержит съёмочные сценарии, постановку, проверки, список реквизита и привязки изображений.
- `sources/videos` содержит локальные копии всех приложенных видеоматериалов.
- `sources/text` содержит тексты исходных сценариев и автоматические расшифровки видео с таймкодами.
- `sources/references` содержит фото комнаты, Паши и конкретных товаров для генерации.
- `sources/generations` содержит полные листы иллюстраций, точные промты и параметры. В `prompts.json` сохранены ссылки и контрольные суммы референсов. Отдельная правка Макимы сохранена с предыдущей версией и промтом.
- `sources/visual-manifest.json` связывает каждый кадр с видео и секундой либо с ячейкой генерации. Сохранены кропы и контрольные суммы.
- `sources/review-notes.json` перечисляет учтённые комментарии и изменения сценариев.

Для пересборки кадров требуется Python с Pillow и `ffmpeg`. В этой рабочей среде используется `/Users/qerg/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 tools/build_plan.py`. Скрипт не обращается к общей базе отметок.

## Съёмочные решения

Мицури — добавлена оригинальная карточка лимитированного выпуска. Индивидуальный номер закрыт в черновом кадре и должен быть закрыт в финальном монтаже. Уточнены тканевый купальник, косы и сёрф.

Резе — камера на уровне лица или чуть ниже, родной коврик, блеск покраски, роспись кожи и обувь.

Макима — один сценарий распаковки, сборки и показа. Чистый блок фигурки со сцены 7 и финал дают самостоятельный второй монтаж. Ушки и красный аксессуар устанавливаются после посадки статуи.

В «Историях коллекционеров» в исходнике восемь текстов при заявленных шести. Сохранены все восемь, ориентировочная длительность 3 минуты 35 секунд. Каждую историю снимаем отдельным дублем.

Для «Дюны» выделено около 47 секунд, чтобы сохранить реплики в понятном темпе. Вступительное «за полминуты» заменено на «коротко». Неспойлерные промовставки выбираются при монтаже, в карте показаны схемы.

Иллюстрации распаковки показывают постановку. Реальную геометрию ложемента и порядок штатных креплений проверяют по товару. Для развлекательных сцен конкретные статуи выбирают из доступной витрины.

Печатных материалов по этим сценариям не требуется. Тексты для телефона и монтажа доступны в сценариях.
